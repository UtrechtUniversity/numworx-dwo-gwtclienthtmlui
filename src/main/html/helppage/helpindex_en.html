Account

Persons

Find a person to edit by entering search criteria in one or more of the fields and click on filter. Click on 'add' to create a new student account.

Edit student

Edit teacher

Here you can connect or disconnect a teacher from your schoolclasses.

Create a student account

Enter one or more fields and select one class to add a new student. If you have no schoolclasses create some first.

Import accounts

Here you can import a list to create multiple accounts.

Results

Here you can select a schoolclass of yours to review its student results. Click on a module name to see the results of activities with in the module. The numbered colored squares can be used to filter results. Comparing class results is not yet possible in this version of Numworx Teacher.

Viewing class results

Click in the table or on a column header to drill down in the student results.

Activity results

Here you can review the activity results of a schoolclass.

Schoolclass management

Select a schoolclass to edit or review or create a new one. When creating a schoolclass you can choose whether or not the modules are presented in a tree structure or not. If you do not set an access key any student of your school may register for the class.

Edit a schoolclass

Edit the basic data of a schoolclass or delete it. Deleting a school class can not be reverted. If a schoolclass is removed its students, teachers, modules and module results remain. However they are no longer connected to the schoolclass. This panel shows all students, teachers and modules connected to the class. Select assign students, move/copy students, connect teachers or assign modules to change the configuration. To remove the students or teacher from a class go to the persons section. If you remove a student from all your classes, you have no access to any of his or her results. However a schooladmin may connect such a student to one of your classes.

Edit a schoolclass

Edit the basic data of a schoolclass or delete it. Deleting a school class can not be reverted. If a schoolclass is removed its students, teachers, modules and module results remain. However they are no longer connected to the schoolclass. This panel shows all students and teachers connected to the class. Select assign students, move/copy students or connect teachers. To remove the students or teacher from a class go to the persons section.

Add a student to a schoolclass

The list contains any student that is assigned to one of your classes. Find a student to edit by entering data in one of the fields and clicking "Filter". Select a single student in the table and click on "Assign" to assign it to the class.

Connect a teacher to a schoolclass

The list contains any teacher in the school. Find a teacher to edit by entering data in one of the fields and clicking "Filter". Select a single teacher in the table and click on "Assign" to assign it to the class..

Copy or move a student

You can copy or move students between the current class and another of your classes. If you want to remove a student from the current class go to the persons section.

Assign modules to a schoolclass

Select a module by searching or browsing in the tree on the left. Modules that were assigned earlier and contain results have a gray checkmark. Modules assigned have a blue checkmark. Modules assigned in the left table are shown in the right table. Click the checkmark to change the assignment. To edit the settings of a assigned module, select it in the right table. When checking/assigning a module in the left table it appears in red in the right table. Edit its settings and click save to complete assignment. Modules are made instantly available to a class unless a date/time range is set. .
